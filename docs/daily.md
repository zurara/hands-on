# 今日一件 · Daily piece

每天一件，全世界同一件。像 Wordle：大家做的是同一块布、同一条围巾，分享的是「我今天也做完了」。

## 规则

- **题目由日期算出来**，不需要服务器。本地日期 `YYYY-MM-DD` → 种子。同一天打开，谁都拿到同一题。
- **手艺每天轮换**（方案 A）：第 0 天刺绣、第 1 天棒针……按 `ORDER` 轮。以后加钩针、羊毛毡、织布机，就排进 `ORDER`，轮换自动变长。第 0 天是 2026-11-21。
- **一题 = 种子 + 目标排数**（8–12 排，由种子决定）。针法、颜色、线头都由种子定，和自由玩完全同一套规则，所以每个人做出来一模一样。
- **做到目标排数就算完成**，记进作品墙。完成后可以接着做，多做的不算分。
- **拆光了不换布**：今日一件拆光，回到同一题的第一排；自由玩拆光才换新布。
- 今日一件和自由玩**分开存档**（`hands-on.daily.<craft>` / `hands-on.<craft>`），互不影响。

## 存档

- `hands-on.days`：`{ "2026-11-21": { craft, rows, at } }`，只记完成的日子。连续天数从这里算。
- 一件作品只要「日期 + 手艺 + 排数」就能完整重画，所以作品墙和分享链接都不用存图片。

## 还没做（按顺序）

1. **作品墙**：工作桌上一面墙，每个完成的日子一格，盖日期章。
2. **分享**：卡片 PNG（作品 + 日期章 + 题目）；链接 `#/day/2026-11-21`，别人点开看到用游戏重画的那一件，下面「今天也来做一件」。
3. **导出 / 导入**作品墙（换浏览器、清缓存不丢）。

## 平台版（以后）

- 激励广告只放两个位置：**补做昨天**（错过的日子看一段补上）、**今日多一色**。绝不在下针时出现。
- 公共作品墙要后台和审核，等平台版有登录再做。
- 自由创作模式：个人开发者在 LINE（台湾）、微信、YouTube 都做不了内购，暂不做付费；可能做成「看广告换一次自由创作」。

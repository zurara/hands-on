# 有手就行 · Hands-on

把打发时间的手作，变成屏幕上的小游戏。一张工作桌，上面放着可以动手的小东西。

Idle-time handcrafts, turned into small screen games: a work table with small things to make.

- **N°01 刺绣 · Embroidery**: thread stitched into the ground, row by row.
- **N°02 棒针围巾 · Knitted scarf**: two wooden needles, four moves per stitch (in, around, through, off).

Play at <https://hands-on.withzurara.com>. Keyboard: press the keys in order. Phone: swipe along the arrows. Grab the loose yarn and pull to unravel.

Plain HTML, CSS and Canvas 2D. No build step, no dependencies, sounds synthesised with WebAudio.
